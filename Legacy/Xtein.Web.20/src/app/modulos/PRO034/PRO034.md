# 📄 PRO-034: Planes Maestros de Producción

## 📖 1. Resumen Ejecutivo
*   **Código de Aplicación:** `PRO-034`
*   **Módulo Pertenciente:** `Producción`
*   **Responsable de Negocio:** `Planeación / Planta`
*   **Descripción:** Interfaz para el balanceo y asignación diaria de cantidades de productos comprometidos en pedidos hacia planes de producción específicos.

---

## 🏗️ 2. Arquitectura y Componentes
La vista está fragmentada en 3 subcomponentes para optimizar el rendimiento de renderizado de Angular. El intercambio de datos se centraliza en el control de cabecera.

### 📐 Estructura de Archivos
*   `PRO034.component.ts`: Orquestador principal.
*   `PRO03401/`: Cabecera de Filtros y Totales.
*   `PRO03402/`: Rejilla Izquierda (Muestra Pedidos/Productos por Plan).
*   `PRO03403/`: Rejilla Derecha (Asignación Matricial Diaria).

### 🔄 Comunicación entre Componentes
*   **Orquestación Central (`events: Subject<any>`):** El padre (`PRO034`) tiene un canal RxJS para replicar eventos entre hermanos.
    *   *Ejemplo*: Si `PRO03401` emite un `plan_seleccionado`, el padre escucha y dispara `Subject.next()` dirigido a `PRO03402` y `PRO03403` para que carguen sus grids.
    *   *Ejemplo 2*: `PRO03403` emite actualización de porcentajes al padre, y el padre la delege a `PRO03401` para pintar la barra de progreso.

---

## 🛠️ 3. Integración con `regbarra` (Barra de Registro)
| Acción de Barra | Comportamiento en la Pantalla |
| :--- | :--- |
| **`r_ini`** | Inicializa con permisos de base de datos. Bloquea las grids en sólo lectura (`readOnly = true`). |
| **`r_modificar`** | Dispara `events.next({ accion: 'set_readOnly', valor: false })` permitiendo editar la cuadrícula de `PRO03403`. |

| **`r_cancelar`** | Aborta cambios no guardados y bloquea rejillas (`r_cancelar`). |

## 🔗 4. Flujo de Datos y Backend (API)
### 📡 Servicios Angular
*   `PRO034Service`: Encapsula los métodos HTTP `.consulta(accion, datos)` y `.save(accion, datos)`.

### 🗃️ Consultas de Base de Datos (`ApiRest`) - endpoint: `/PRO023/consulta`

#### 1️⃣ `PLANES PROD` (Disparada en `PRO03401` -> `ngOnInit`)
*   **Descripción:** Lista todos los planes de producción del sistema para llenar el selector de cabecera.
*   **Parámetro (`prmDatos`):** `{}` (Vacío)
*   **Retorno:** Array de objetos:
    ```json
    [{ "CONSECUTIVO": 8, "FECHA_INICIO": "2026-03-01", "FECHA_FINAL": "2026-03-30", "NOMBRE_PLAN": "MARZO 26" }]
    ```

#### 2️⃣ `PEDIDOS PMP` (Disparada en `PRO03402` y `PRO03403`)
*   **Descripción:** Obtiene todos los productos y órdenes asociadas a un plan específico para cargarlos en los grids.
*   **Parámetro (`prmDatos`):**
    ```json
    { "ID_PLAN": 8, "FECHA_INICIO": "2026-03-01", "FECHA_FINAL": "2026-03-30" }
    ```
*   **Retorno:** Items de pedido con stock comprometido y estado.

#### 3️⃣ `PROGRAMACION` (Gatillada en `PRO03402` -> `addColumn`)
*   **Descripción:** Simula la distribución de cantidades en el tiempo para renderizar columnas dinámicas matriciales de Plantas (`PL01`, `PL02`).
*   **Parámetro (`prmDatos`):** `{ "PRODUCTOS": Array<Item> }`

## 💾 5. Operaciones de Escritura (`ApiRest`) - endpoint: `/PRO023/save`

#### 📝 `UPDATE AGENDA` (Gatillada en `PRO03403` -> `programarPedidos`)
*   **Descripción:** Guarda la distribución de cantidades diarias de un producto en el calendario de producción.
*   **Parámetro (`prmDatos`):**
    ```json
    { 
      "PRODUCTOS": [{ "ID_PLAN": 8, "PRODUCTO": "PF001428", "CANTIDAD_PROGRAMADA": 12, "FECHA_PROGRAMADA": "2026-03-20" }], 
      "USUARIO": "ADMIN", 
      "TIPO": "PEDIDO" 
    }
    ```

---

## 🚨 5. Reglas de Negocio Críticas
1.  **Fechas de Planes:** Solo se pueden editar cantidades de un plan cuya fecha no haya expirado (fecha futura o presente).
2.  **Suma de Cantidades:** La suma de la asignación diaria en `PRO03403` no debería superar la cantidad `COMPROMETIDA` del pedido original, a menos que el perfil de usuario lo permita de forma explícita.
