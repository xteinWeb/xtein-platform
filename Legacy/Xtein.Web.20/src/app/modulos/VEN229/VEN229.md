# 📄 VEN-229: Gestión de Pedidos (Maestro - Detalle)

## 📖 1. Resumen Ejecutivo
*   **Código de Aplicación:** `VEN-229`
*   **Módulo Pertenciente:** `Ventas`
*   **Responsable de Negocio:** `Comercial / Facturación`
*   **Descripción:** Formulario complejo para la captura, cotización y seguimiento de pedidos de clientes, gestionando precios, impuestos (IVA) y descuentos en tiempo real.

---

## 🏗️ 2. Arquitectura y Componentes
`VEN229` es un componente monolítico de alta densidad lógica que administra múltiples vistas a través de estructuras de datos en memoria local (`_prev`).

### 📐 Estructura de Componentes UI (Formularios)
*   **`formPedidoBasico`:** Datos de cabecera (Cliente, Fecha, Moneda, Tipo Venta).
*   **`formPedidoAdicional`:** Logística (Dirección de entrega, observaciones).
*   **`gridPedidoItems`:** Cuadrícula central de productos con cálculos matriciales.

### 🔄 Lógica de Sincronización
No utiliza subcomponentes separados, por lo que la comunicación es interna mediante métodos. Utiliza **Buffers de Respaldo** (`DPedido_prev`, `DPedidoItems_prev`) para el control de cambios:
*   Al activar **Modificar**, se clona el objeto a `_prev`.
*   Al activar **Cancelar**, se hace un `JSON.parse(JSON.stringify(_prev))` para restaurar la cuadrícula instantáneamente sin llamar a Base de Datos.

## 🛠️ 3. Integración con `regbarra` (Barra de Registro)
| Acción de Barra | Comportamiento en la Pantalla |
| :--- | :--- |
| **`r_ini`** | Inicializa y bloquea el formulario. Carga los informes asignables desde la tabla de reportes. |
| **`r_nuevo`** | Vacía todos los formularios (`DPedido = new clsPedidos()`) y abre el modo inserción con la fecha del día. |

## 🔗 4. Flujo de Datos y Backend (API)
### 📡 Servicios Angular
*   `VEN155Service`: Encapsula los métodos HTTP de `/consulta`, `/save` y `/delete`.

---

### 🗃️ Consultas de Lectura (`ApiRest`) - endpoint: `/VEN229/consulta`

Las consultas en `VEN229` siguen un ciclo de vida síncrono para garantizar que los cálculos de IVA y Totales no fallen por falta de datos maestros.

#### 1️⃣ Carga de Catálogos (Combos)
*   **Acciones:** `CLIENTES`, `DOCUMENTOS`, `BODEGAS`, `LISTA_PRECIOS`.
*   **Descripción:** Se disparan en ráfaga al abrir la aplicación para precargar los dropdowns (`DxDropDownBox`).
*   **Parámetro:** `{}` (Vacío)

#### 2️⃣ `CARGAR_PEDIDO` (Lectura del Maestro)
*   **Descripción:** Recupera la información de cabecera de un pedido guardado.
*   **Parámetro (`prmDatos`):**
    ```json
    { "ID_DOCUMENTO": "PE", "CONSECUTIVO": 105 }
    ```
*   **Retorno:** Objeto único que se mapea a `DPedido: clsPedidos`.

#### 3️⃣ `CARGAR_ITEMS` (Lectura del Detalle)
*   **Descripción:** Recupera la rejilla de productos asociados al pedido actual.
*   **Parámetro (`prmDatos`):** El mismo del Maestro (`ID_DOCUMENTO` y `CONSECUTIVO`).
*   **Retorno:** Array de objetos para `DPedidoItems: clsPedidosItems[]`.

---

## 💾 5. Operaciones de Escritura (`ApiRest`) - endpoint: `/VEN229/save`

#### 📝 `GUARDAR_PEDIDO` (Creación o Modificación)
*   **Descripción:** Guarda la cabecera y el detalle en una sola transacción atómica enviando los items serializados.
*   **Parámetro (`prmDatos`):**
    ```json
    {
      "CABECERA": { "ID_DOCUMENTO": "PE", "ID_CLIENTE": "900...", "TOTAL": 1500000 },
      "ITEMS": [
        { "PRODUCTO": "PF001", "CANTIDAD": 10, "VALOR_UNITARIO": 15000 },
        { "PRODUCTO": "PF002", "CANTIDAD": 5, "VALOR_UNITARIO": 20000 }
      ],
      "USUARIO": "VENDEDOR_01"
    }
    ```
*   **Retorno:** `{ "ErrMensaje": "", "CONSECUTIVO_GENERADO": 106 }`

---

## 🗑️ 6. Operaciones de Borrado (`ApiRest`) - endpoint: `/VEN229/delete`

#### ❌ `ANULAR_PEDIDO`
*   **Descripción:** Cambia el `ESTADO` del maestro a `ANULADO`. (Generalmente no se borra físicamente).

---

## 🚨 5. Reglas de Negocio Críticas
1.  **Cálculo de Gravámenes (IVA):** No se calculan estáticamente. Se leen del Array `DPedidoGrav` para permitir múltiples tasas (0%, 5%, 19%) en un mismo pedido.
2.  **Validación de Stock:** Al heredar de librerías de inventario, si la orden tiene el flag `conExistencias` prendido, el grid gatillará un bloqueo de guardado si un item está en rojo.
